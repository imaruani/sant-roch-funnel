Comment utiliser l'outil

3 étapes pour rédiger tes emails Sant Roch.

1
🌳
Navigue dans l'arbre
Repère un nœud email dans le funnel et clique dessus pour l'ouvrir. Tu peux aussi passer en vue Tableau pour voir tous les emails listés.
Scroll → zoomer Drag → se déplacer Clic droit → options
↓
2
✏️
Rédige ta V2
V1 = la version actuelle importée depuis Mariana Tek (ne pas modifier).
V2 = ta nouvelle version à écrire. Garde les {{variables}} de V1.
B I U → mise en forme ≠ Diff → comparer V1 / V2 Voir sur MT → ouvrir dans Mariana Tek
↓
3
💾
Sauvegarde
Clique sur Sauvegarder dans le panneau — ou attends 2 secondes, la sauvegarde est automatique. Tes données sont synchronisées sur tous tes appareils.
Ctrl+Z → annuler ↓ CSV / JSON → exporter
🎓 V1 · V2 · Diff — Comment ça marche
Comprendre les codes couleur, la logique V1/V2 et la comparaison Diff
① Les deux types de nœuds
🔵 À personnaliser
L'email existe déjà dans Marianatek.
V1 est pré-rempli avec le texte MT actuel.
Tu rédiges ta version dans V2.
🟠 À créer
L'email n'existe pas encore dans MT.
Pas de V1 importé.
Tu rédiges directement ta version.
💡 Exemples bleus : Confirmation réservation, Rappel J-1, Liste d'attente… ces emails partent déjà, tu les améliores.
💡 Exemples oranges : Relance J+3, Réactivation J+30, Fête des mères… à créer de zéro dans Explore Growth.
② V1 et V2 côte à côte
